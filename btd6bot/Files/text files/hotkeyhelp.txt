[Supported keys]
- letters (a-z), digits (0-9) and most keys that input text symbols (+ - * etc.)
- following special/modifier keys:
    ctrl, ctrl_l, ctrl_r, enter, space, shift, shift_l, shift_r, backspace, tab, delete, home, 
    end, page_up, page_down, up, down, left, right, f1-f12
  ## alt, alt_l, alt_r, alt_gr are all supported, but only alt_l seems to register ##
- various other numerical keycodes are supported, but these will simply show as <KEYCODE>.
  For example numpad keys 0-9: <96> for num0, <97> for num1, ... up to <105> for num9.
  ## Same button will most likely use a different keycode on other operating system! ##
=> unfortunately, some keys have API limitations and won't work. For example pressing the "/" 
key above numpad produces keycode "111": game shows "NumpadDivide" yet API treats it as "-".

[How to set a hotkey]
- Click the hotkey row from panel that you'd like to modify - row is now highlighted.
- Press 'Set Hotkey' button below hotkey box. When button is grayed out, press any supported key.
- You should now see the right side of '=' change on that row you chose.
## Remember to scroll the hotkey panel down to access rest of the hotkeys ##
## Some keys might not get displayed correctly, but should still work ##

[Hotkey explanations]
Most hotkey meanings should be easy to interpret but here's a breakdown:
 'dart monkey',..., 'beast handler' are monkeys + 'hero' stands, unsurprisingly, for hero.                       
 'upgrade ...' are for the corresponding upgrade paths.  
 'target change' and 'target reverse' change targeting forward and backward, respectively.                        
 'special 1' and 'special 2' are special ability hotkeys. 
 'sell' for tower selling, 'play' for pressing the play/fast forward button.  
 'ability ...' for abilities 1-10.
 'merge beast' for beast handler merging.
 'centered path' for switching center location for x-x-2+ aces.

[Custom gui hotkeys]
 'pause' = pauses the bot during plan execution, 
 'start-stop' = begins or stops (and resets) the current bot loop/queue,
 'exit' = stops the program and closes all gui windows
